# About
IRON LOG is a personal project I built while learning and improving my web development skills. The goal was to create a workout tracker that is actually useful to me while experimenting with React, UI design, local storage, PWAs, and deployment.

### Important
AI tools were used throughout the development process for debugging, refactoring, brainstorming, and implementing some features. This project is also a hands-on way for me to learn and improve my web development skills.
