# About

adergym is the final version of **IRON-LOG**, my personal workout tracking app. What started as a project to track my own training evolved into a more complete application, built while learning and improving my web development skills.

The project explores React, UI/UX design, local storage, Progressive Web Apps (PWAs), data management, and deployment. My goal was to build something practical for my own workouts while learning by building and iterating on a real project.

### Important

AI tools were used throughout the development process for brainstorming, debugging, refactoring, and implementing some features. This project is also a hands-on way for me to learn, experiment, and improve my web development skills.
